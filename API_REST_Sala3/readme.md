# Aplicación Web - Aula API Lab

Aplicación web desarrollada para consumir la *Aula API Lab*, permitiendo la consulta de inventario de productos, creación de pedidos y gestión segura mediante autenticación basada en API Key.

## Tecnologías Utilizadas
- *HTML5 & JavaScript (ES6+)* para la lógica del cliente y consumo de endpoints.
- *Bootstrap 5* para el diseño de la interfaz de usuario responsiva.
- *Fetch API* para solicitudes HTTP asíncronas y manejo de respuestas JSON.

## Características Principales
1. *Autenticación por API Key:* Almacenamiento seguro en sesión local para interactuar con la API.
2. *Consulta de Productos:* Listado en tiempo real del inventario disponible.
3. *Gestión de Pedidos:* Formulario dinámico para registrar nuevos pedidos y visualizarlos en un panel de control.
4. *Manejo de Errores:* Validación de respuestas HTTP y alertas informativas ante fallos de conexión.

## Instrucciones de Ejecución
1. Clona este repositorio o descarga los archivos en tu equipo local.
2. Abre la plataforma [Aula API Lab](https://darkred-rook-511555.hostingersite.com/index.php) para registrarte y obtener tu *API Key*.
3. Abre el archivo index.html en cualquier navegador web moderno o ejecútalo mediante un servidor local (como Live Server en Visual Studio Code).
4. Ingresa tu API Key en la interfaz de configuración para comenzar a interactuar con los endpoints.
